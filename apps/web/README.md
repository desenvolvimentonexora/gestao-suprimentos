# apps/web

Front da Gestão de Suprimentos (React + TypeScript + Vite). Ver `CLAUDE.md` na raiz do repositório para as regras e fases do projeto.

```bash
npm install
npm run dev
npm run lint && npm run typecheck && npm run test
```

Variáveis de ambiente em `.env.local` (não commitado) — ver `.env.example`.
